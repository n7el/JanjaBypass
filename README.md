# JanjaBypass

Script para contornar o bloqueio regional e restaurar as funções de vídeo e transmissão de tela no Discord (Brasil).

---

## ❔ Como Usar

1. Baixe o script: [Bypass.cmd](https://github.com/n7el/JanjaBypass/releases/latest/download/Bypass.cmd)
2. Execute o script e aguarde o Discord reiniciar.
3. Pronto, funções liberadas.

---

O script funciona de uma forma bem simples: basicamente, ele inicia o seu Discord com um proxy internacional e, logo após a inicialização, o desativa. Isso faz com que as funções de compartilhamento de tela e câmera voltem a funcionar normalmente, sem prejudicar o ping — mantendo a mesma latência que você teria sem VPN ou proxy.
